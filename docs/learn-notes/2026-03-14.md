## 🌙 下午学习计划：核心执行链路拆解

针对 `BindingTest.java` 中的 `shouldSelectBlogWithPostsUsingSubSelect` 方法，我们将重点攻克以下三个主干阶段：

### **阶段一：会话开启与环境准备 (openSession)**
- **关注点**：`SqlSessionFactory.openSession()` 内部如何创建 `Transaction` 和 `Executor`。
- **关键类**：[DefaultSqlSessionFactory.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/session/defaults/DefaultSqlSessionFactory.java)
- **目标**：理解 `Configuration` 是如何将配置传递给 `Executor` 的。

### **阶段二：代理对象的生成 (getMapper)**
- **关注点**：`session.getMapper(BoundBlogMapper.class)` 的底层逻辑。
- **关键类**：[MapperProxyFactory.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/binding/MapperProxyFactory.java) 和 [MapperProxy.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/binding/MapperProxy.java)
- **目标**：搞清楚 MyBatis 如何通过 JDK 动态代理将接口“实例化”。

### **阶段三：SQL 执行全过程 (mapper.select...)**
这是最核心的部分，建议按照以下顺序 Debug：
1.  **拦截请求**：[MapperProxy.invoke()](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/binding/MapperProxy.java) —— 它是如何把方法名映射到 SQL 语句上的？
2.  **调度执行**：[CachingExecutor.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/executor/CachingExecutor.java) —— 理解二级缓存的入口。
3.  **核心执行**：[BaseExecutor.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/executor/BaseExecutor.java) —— 一级缓存的工作原理。
4.  **JDBC 交互**：[PreparedStatementHandler.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/executor/statement/PreparedStatementHandler.java) —— 真正的 `PreparedStatement` 在哪里创建和执行？
5.  **结果映射**：[DefaultResultSetHandler.java](file:///D:/learn/mybatis-learn/mybatis-3/src/main/java/org/apache/ibatis/executor/resultset/DefaultResultSetHandler.java) —— 它是如何根据 XML 中的 `ResultMap` 将数据库字段塞进 Java 对象的？
